# 성공 사례와 전체 파이프라인 리뷰 영상

이 자료는 **사람 영상 없이 실행한 bootstrap/fast 5단계 경로**의 증거다. 실제 사람 영상 기반 full 성공 사례는 없다. 기존 실행의 선택 결과·작업 JSON·학습 로그·평가표를 사용하고, 저장된 모델과 제어기를 실제 시뮬레이터에서 다시 실행해 촬영했다. 새 학습은 하지 않았다.

## 영상을 읽는 방법

- **교사**는 Panda 데모의 잡기 상대 위치·들기 높이를 사용하는 규칙 기반 제어기다. 원본 전체 동작을 자동으로 변환한 모델이 아니다.
- **학습 정책**은 실제로 실행된 성공 UR5e 궤적을 학습한 신경망이다. 정확한 시뮬레이터 상태와 규칙 기반 단계 정보를 입력받는다.
- **초록색 테두리**는 Can이 놓여야 하는 목표 칸이다. 영상 아래에 Can 자체의 칸 내부 여부와 잡기 접촉 여부를 표시했다.
- **1초 추가 검사**에서도 같은 제어기/정책을 계속 사용했다. 학습 정책의 마지막 동작을 scripted 동작으로 교체하지 않았다.
- **정지한 패널**에 실행 종료 표시가 있으면 해당 영상이 끝나 마지막 프레임을 유지하는 것이다.
- 1·2단계 화면은 실제 JSON/메타데이터를 보여 주는 설명 카드다. 존재하지 않는 사람 영상이나 추론 결과를 만들어 보여 주지 않는다.
- Panda scripted 영상은 별도로 실행한 소스 정책 분기다. 원본 HDF5 궤적을 재생한 영상으로 해석하지 않는다.

## 원래 실험 집계

| 실행 | 원본 정보 기반 UR5e 교사 | 학습 정책 전 → 후 | 전체 평균 XY 오차 전 → 후 |
|---|---:|---:|---:|
| fast | 10/10 | 9/10 → 9/10 | 81.55 → 84.58mm |
| bootstrap | 3/3 | 0/3 → 1/3 | 653.82 → 258.88mm |

fast의 피드백은 성공률 개선이 없었다. bootstrap은 한 사례가 개선됐고 두 평가 사례는 여전히 실패한다. 9/10은 평가 열 번의 성적이며 광범위한 일반화 성능을 뜻하지 않는다.

## 재생성

```bash
.venv/bin/python -m pip install -r requirements-review.txt
bash scripts/launch_review_media.sh review_media_20261105_success all
cat runs/review_media_20261105_success/status.json
tail -f runs/review_media_20261105_success/logs/review.log
```

필요한 frozen checkpoint와 trajectory NPZ는 원래 실행의 gitignored `runs/`에 있다. 따라서 영상·문서만 내려받은 새 clone에서 생성기를 실행하려면 해당 원본 실험을 먼저 실행하거나 원본 체크포인트·궤적을 준비해야 한다. 재생성은 해시가 일치하는 완료 에피소드를 재사용하며 원래 학습 결과를 덮어쓰지 않는다.
